
# Phase 1: Project Setup & Data Acquisition

## 1. Dataset Selection

The dataset used in this project is **KFUPM-JRCAI/arabic-generated-abstracts**, obtained from the Hugging Face Datasets platform.

Although the original dataset contains three generation-method subsets, the **from_title_and_content** subset was selected as the dataset used for the remainder of the project. This subset represents a content-aware generation approach in which the models generate abstracts using both the paper title and content.

The selected subset contains **2,574 original samples** and five text fields:

- `original_abstract`
- `allam_generated_abstract`
- `jais_generated_abstract`
- `llama_generated_abstract`
- `openai_generated_abstract`

The `original_abstract` field represents human-written Arabic abstracts, while the four model-generated fields represent AI-generated abstracts.

---

## 2. Dataset Loading and Initial Inspection

The dataset was loaded directly from Hugging Face using the Python `datasets` library.

The selected `from_title_and_content` subset contains:

- **2,574 rows**
- **5 columns**

The five columns correspond to one human-written abstract and four AI-generated versions.

The data was converted into a Pandas DataFrame to facilitate data inspection and subsequent processing.

---

## 3. Raw Data Quality Assessment

Following the project requirements, data-quality checks were performed on the **original raw dataset before reshaping** the data into the final classification format.

The following aspects were examined:

1. Missing values
2. Duplicate rows
3. Empty text values
4. Data types
5. Basic text-length characteristics

### 3.1 Missing Values

All five text columns were checked for missing values.

The analysis found:

**Total missing values = 0**

Therefore, no missing-value problem was identified in the selected raw subset.

### 3.2 Duplicate Rows

Duplicate detection was performed on the complete raw rows before any reshaping or labeling operation.

The result was:

**Number of duplicate raw rows = 0**

Therefore, the selected raw subset does not contain duplicate records based on complete-row comparison.

It is important to distinguish this result from repeated text values that may appear after reshaping the dataset. During reshaping, the original human abstract is placed into the Human class while the generated abstracts are placed into the AI class. Consequently, repeated text values in the reshaped representation should not automatically be interpreted as duplicate raw records.

### 3.3 Empty and Invalid Text Values

The text fields were also examined for empty values and basic type consistency.

The analysis did not identify empty text entries in the selected raw data. The text fields were represented as string/object values suitable for subsequent Arabic text preprocessing.

---

## 4. Reshaping and Label Assignment

After completing the raw data-quality checks, the dataset was transformed from its original five-column structure into a binary classification format.

The human-written abstracts from `original_abstract` were assigned the label:

**Human**

The four generated abstract columns were combined and assigned the label:

**AI**

The resulting classification dataset contains two columns:

| Column | Description |
|---|---|
| `text` | Arabic abstract text |
| `label` | Binary class: Human or AI |

The final dataset contains:

**12,870 text samples**

consisting of:

- **2,574 Human samples**
- **10,296 AI samples**

---

## 5. Class Distribution

The final classification dataset contains an imbalanced class distribution.

| Label | Number of Samples | Percentage |
|---|---:|---:|
| Human | 2,574 | 20% |
| AI | 10,296 | 80% |
| **Total** | **12,870** | **100%** |

The imbalance occurs because each original human abstract is associated with four AI-generated versions from different generation models.

This class distribution will be considered in the subsequent preprocessing, exploratory analysis, feature engineering, and model evaluation stages.

---

## 6. Phase 1 Findings

The main findings from Phase 1 are summarized below:

- The project dataset was successfully retrieved from Hugging Face.
- The **from_title_and_content** subset was selected as the only dataset used for the project.
- The selected raw subset contains **2,574 samples and 5 text columns**.
- No missing values were detected.
- No duplicate raw rows were detected.
- No empty text values were identified.
- Data-quality checks were completed **before reshaping**, ensuring that repeated values created by the reshaping process were not incorrectly classified as duplicate raw records.
- The data was then reshaped into a binary classification dataset containing `text` and `label`.
- The final classification dataset contains **12,870 samples**.
- The final dataset consists of **20% Human** and **80% AI-generated** texts.

## 7. Conclusion

Phase 1 established the dataset and verified its basic quality before any transformation was performed. The `from_title_and_content` subset was selected as the project's working dataset. The raw data passed the initial quality checks, with no missing values or duplicate raw rows detected.

After the quality assessment, the dataset was transformed into a binary text-classification format containing Human and AI-generated abstracts. The resulting dataset will be used as the input for the Arabic-specific preprocessing and exploratory data analysis activities in Phase 2.
